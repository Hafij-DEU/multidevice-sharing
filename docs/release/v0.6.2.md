MeshDrop 0.6.2: light and dark themes, tidier screens.

- **Theme:** Settings → Theme picks System, Light or Dark on each device (it used to follow only the system).
- **More menu:** Remote, Continue and Watch party now have colourful icons like the rest.
- **Settings:** each checkbox now sits on the same line as its text on a phone.
- **Tailscale setup guide in the app:** More → Mesh → Internet access → Tailscale Funnel shows each step with Copy buttons and links, and ticks off what is done.
- **Internet access with Tailscale:** when your tailnet hasn't allowed Funnel yet, MeshDrop now shows the approval page as a link right away. Before, it waited without end and started more and more stuck `tailscale` commands.
- **Sound to another device:** on the same Wi-Fi, a PC's Remote page has **Play this PC's sound there** (to another PC), and the phone's Remote page has **Play phone sound on PC** (music, videos and games the phone plays; Android asks once to allow capturing). The receiving PC must allow the sender on its Remote page ("Devices that may control this PC").
- **Phone as webcam:** starting it again right after stopping works now (it found the camera still busy), and you can pick the **back camera** or switch cameras while it runs.
- **A link to send files to you:** Guests → Internet links → tick "Let them send files to you" without choosing any files. Send the link to anyone: they open it in a browser and upload one or many files. Tick "Accept their files without asking me" too, and the files land on your PC at once, with no question.
- **Fixed:** a file sent to you through an internet link (or from LocalSend) now always asks you to Accept. Before, the question only showed while a Wi-Fi guest QR code was open, so the sender waited forever.
- Clicking a MeshDrop notification now opens MeshDrop.
- A new README with screenshots and a short video.
