MeshDrop 0.6.2: light and dark themes, tidier screens.

- **Theme:** Settings → Theme picks System, Light or Dark on each device (it used to follow only the system).
- **More menu:** Remote, Continue and Watch party now have colourful icons like the rest.
- **Settings:** each checkbox now sits on the same line as its text on a phone.
- **Internet access with Tailscale:** when your tailnet hasn't allowed Funnel yet, MeshDrop now shows the approval page as a link right away. Before, it waited without end and started more and more stuck `tailscale` commands.
- A new README with screenshots and a short video.
