MeshDrop 0.8.2: a lighter PC app, and the shared clipboard works on GNOME Wayland.

- **Less memory on Linux:** the clipboard reader (a second, hidden copy of the app) no longer runs while the shared clipboard is off, which is the default. That saves about 30 MB. Sending the clipboard starts it when needed, and it closes itself after 30 s without use.
- **Shared clipboard on GNOME Wayland:** the PC used to read an empty clipboard there, so copies never reached your other devices. It now reads what you copy.
- **Windows installer:** `MeshDrop-Setup-0.8.2.exe` is attached to this release.
- No features removed.
- This app was generated with AI. Developer support may not be available.
