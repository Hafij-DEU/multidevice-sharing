MeshDrop 0.9.3: the Wi-Fi tab shows which network you are on, on every Android version.

- **"Connected" badge on Android:** in the Wi-Fi tab, the saved network your phone is on right now gets a green "Connected" badge, matching what Android shows as "Connected via MeshDrop". The tab re-checks the connection every few seconds while it is open, so the badge appears on its own after you tap Connect.
- **Fixed "Not connected to Wi-Fi" on Android 13 and newer:** Android only tells an app the name of the current network when the app may use Location. MeshDrop used to ask for Location only on Android 12 and older, so newer phones wrongly showed "Not connected". The Wi-Fi tab now asks for Location (while using the app) on every version.
- **If you say no to Location:** the "This device" card still says you are connected and shows the band, signal and speed, explains that Android hides the name, and offers an "Allow location" button. With Location switched off in quick settings, it says so.
- MeshDrop uses Location only to read the name of the Wi-Fi network you are on. It does not track or store where you are.
- 0.9.2 was not published; its changes are included here.
- No features removed.
- This app was generated with AI. Developer support may not be available.
