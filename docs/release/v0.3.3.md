MeshDrop 0.3.3: several sync folders, a Deleted folder, lighter on battery.

**Folder sync**
- **More → Sync** holds as many folders as you like, each with its own devices. Folders match by **name**: give a folder the same name on each device (it starts as the folder's own name; rename it on its card).
- **Nothing is lost by accident:** a file deleted or replaced on another device is kept in that folder's **Deleted** folder, at the same path. Deleted is not synced; empty it yourself when you don't need it.
- **Stop syncing** keeps a folder's files. Your existing synced folder carries over, and devices still on 0.3.0/0.3.1 keep syncing with it.

**Android: always ready, lighter on battery**
- MeshDrop starts at boot (also after fast reboots on Xiaomi), keeps running in the background and keeps receiving.
- With the screen off it works more gently: folder sync and photo backup check every 15 minutes instead of every minute, and the shared clipboard is only checked while MeshDrop is open. A device that shows up, Sync now, or a partner's change still syncs at once.
- On Xiaomi/HyperOS turn on **Autostart** for MeshDrop (More → Settings → Keep MeshDrop alive).
