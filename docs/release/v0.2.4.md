MeshDrop 0.2.4: unpair and pair again.

- **More → Devices** lists the devices this one trusts. **Unpair** (tap twice) stops trusting a paired device and drops its unfinished sends.
- An unpaired device on the same Wi-Fi shows up again under **Send → Add a device**, where **Pair** pairs it again (press Pair on both devices). Useful after reinstalling MeshDrop on a device.
- Mesh members are removed on the hub PC (More → Mesh → Revoke).
