MeshDrop 0.7.1: no more freezes on Linux.

- **Linux desktop no longer freezes:** the app reads the clipboard every second. When another app held the clipboard and was slow to answer, MeshDrop's window, transfers, sound and connections could stop for up to a minute. Clipboard reads now run in a small helper process. A read that takes longer than 2 seconds is dropped, and MeshDrop keeps running.
- The helper uses about 110 MB of memory and closes with the app.
- No changes on Android, Windows or the browser extension; their version numbers follow the desktop app.
- This app was generated with AI. Developer support may not be available.
