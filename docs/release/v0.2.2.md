MeshDrop 0.2.2: speed, previews, right-click send, shared clipboard.

- **Speed and time left** in every progress bar ("98 MiB/s · 4 s left").
- **Received previews:** images and videos show a thumbnail; tap a file or its picture to open it.
- **Send from the Files app (Ubuntu):** right-click files → Scripts → Send with MeshDrop. MeshDrop opens on Send with the files ready.
- **Shared clipboard** (Settings, off by default): text you copy goes to your online devices. On the phone this works while MeshDrop is open (Android only lets the app in front read the clipboard); the clipboard tile still works any time.

Video previews on Ubuntu use the thumbnails the Files app already made.
