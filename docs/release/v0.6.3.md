MeshDrop 0.6.3: MeshDrop for Windows 11.

- **Windows 11 installer:** download `MeshDrop-Setup-0.6.3.exe` and run it (it asks for administrator once). Like the Ubuntu .deb, it installs MeshDrop for everyone on the PC with Start menu and desktop shortcuts, lets your phone through Windows Firewall, puts the `meshdrop` command line on PATH and adds Explorer's right-click **Send to → MeshDrop**. Windows shows "Windows protected your PC" because the installer is not signed yet: click **More info → Run anyway**.
- **What works on Windows:** sending and receiving files, folders, text and the clipboard, pairing, the mesh and hub, guests and internet links, folder sync and photo backup, watch party, Continue, and the phone as a remote (touchpad, keyboard, media keys, presenter laser, lock/sleep/shut down, open Start menu apps, ring). Settings → Keyboard shortcut works too, and Settings → Start at login uses Windows' Startup apps.
- **Not on Windows yet:** sound, camera and microphone streaming (they use Linux's PipeWire). The phone says so when you try.
- **Android:** no changes; keep using `MeshDrop-0.6.2.apk` (attached here too).
- **Fixed (all platforms' shared code, seen on Windows):** received file paths, the smart inbox sorting files into Images/Videos/…, the default name of a synced folder, file names on the Inbox page, and starting again after a crash on first start.
