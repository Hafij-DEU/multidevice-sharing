MeshDrop 0.7.0: No Wi-Fi mode. Your devices stay connected with no Wi-Fi router.

- **Bluetooth links:** paired devices connect over Bluetooth by themselves when they share no network. Each device can be set to *Auto*, *Wi-Fi only* or *Bluetooth only*, and Settings → *Send everything over Bluetooth* sends all traffic over Bluetooth. Files, clipboard, remote control, media keys, notifications and sound work over Bluetooth. Sound is sent as Opus so it fits the link. The camera still needs Wi-Fi.
- **Hotspots:** Settings → No Wi-Fi → *Start a hotspot here*, on the PC (NetworkManager) or on a phone (a local-only hotspot that never shares mobile data). Devices linked over Bluetooth get the name and password by themselves. Other devices scan a QR code or type them in. Phones ask before they join.
- **USB and Bluetooth tethering:** the in-app help shows how to connect them.
- **No mobile data:** on a phone's hotspot or tether, the PC takes no internet route or DNS from the phone (Settings → *Never use the phone's mobile data*, on by default). This changes the running connection only. Your saved network profiles are not changed.
- **Live sound:** relayed sound no longer falls behind after a Wi-Fi stall.
- Not yet tested on every phone: some phones offer only WPA3 hotspots, which the PC may fail to join. If that happens, start the hotspot on the PC instead.
- This app was generated with AI. Developer support may not be available.
